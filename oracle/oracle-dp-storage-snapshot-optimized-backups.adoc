= Storage Snapshot Optimized backups

:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ../media/

[.lead]
Oracle Snapshot Optimized Backups was a method of point-in-time recovery that allowed a user to perform a recovery using snapshots without placing the database in hot backup mode.

Users can still recover from snapshots without the use of backup mode, but only complete recovery using RECOVERY AUTOMATIC is supported. Incomplete recovery using the SNAPSHOT TIME method to indicate the creation time of the snapshot.
