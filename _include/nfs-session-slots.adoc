NFS session slots are the NFSv4.X equivalent of NFSv3 slot tables. The default value is usually 64. A value of 180 is optimum because it matches the session limit in ONTAP.

Example of setting the max_session_slots parameter:

....
# cat /etc/modprobe.d/nfsclient.conf 
 options nfs max_session_slots=180
....

This parameter is used by a kernel module that loads on startup. Unlike the NFSv3 slot table parameter, it is not dynamic. A reboot is required for this to change effect. 

[CAUTION]
Failure to set this parameters may have significant effects on performance. Performance can be significantly limited because the linux OS is not issuing sufficient I/O.
